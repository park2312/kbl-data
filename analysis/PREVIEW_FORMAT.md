# KBL Preview Format

Use this layout for every future KBL game preview.

## 1. Headline
- Predicted winner and win probability for both teams.
- Predicted score.
- Confidence level.

## 2. Quarter-structure view
Always split the game into two rule/rotation environments:
- Q1/Q4: one-foreign-player structure.
- Q2/Q3: two-foreign-player structure.

For each environment show:
- recent point differential / stint evidence,
- projected matchup edge,
- short reason,
- note when evidence comes from different opponents rather than a direct matchup.

## 3. Major stint table
Show major five-man groups or core members in a table:
- Team
- Quarter group (Q1/Q4 or Q2/Q3)
- Main members
- Recent stint result
- Edge / concern

Do not list every micro-stint unless requested. Prioritize the longest and most repeated groups.

## 4. Strengths and weaknesses
For both teams show:
- strongest 2-4 advantages,
- strongest 2-4 weaknesses,
- matchup-specific counter.

## 5. Visual readability
Use charts/tables before long prose.
Preferred order:
1) win probability
2) predicted score
3) Q1/Q4 vs Q2/Q3 edge
4) major stint table
5) strengths/weaknesses
6) tactical detail, interviews, injuries, news

## 6. Evidence hierarchy
1. Official KBL box/PBP/scoreChart/leadTrack/shot/stint
2. Coach/player interviews
3. Beat reports / on-site reporting
4. Analyst/video observations
5. User live observations, verified when possible
6. Inference

Use interview/injury/role-change information as prediction inputs, not decorative context.
